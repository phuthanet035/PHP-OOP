PHP OOP - The __construct() Function

สรุปแนวคิดและตัวอย่างการใช้งานฟังก์ชันสร้างออบเจกต์เริ่มต้น (Constructor)

💡 หัวใจสำคัญของ __construct()

  • ทำงานอัตโนมัติ: เป็นฟังก์ชันพิเศษที่จะถูกเรียกใช้ทันทีทุกครั้งที่มีการสร้าง Object ใหม่ด้วยคำสั่ง new
  • ลดโค้ดซ้ำซ้อน: ช่วยให้เราส่งค่าเริ่มต้นเข้าไปตั้งค่าให้ตัวแปร (Properties) ได้ทันทีตั้งแต่บรรทัดแรก โดยไม่ต้องสร้างเมธอดพวก set_name() มาสั่งงานซ้ำซ้อน
  • กฎไวยากรณ์: ชื่อฟังก์ชันต้องเริ่มต้นด้วยเครื่องหมาย Underscore 2 ตัวเสมอ (__construct)

💻 ตัวอย่างโค้ดและการทำงาน

<?php
class Fruit {
    public $name;
    public $color;

    // 1. คอนสตรัคเตอร์จะรอรับค่าทันทีที่กดสร้างวัตถุ
    function __construct($name, $color) {
        $this->name = $name;
        $this->color = $color;
    }

    function get_details() {
        echo "Name: " . $this->name . ". Color: " . $this->color . "<br>";
    }
}

// 2. ส่งค่า 'Apple' และ 'Red' เข้าไปในวงเล็บตอนสร้าง Object
$apple = new Fruit('Apple', 'Red');
$apple->get_details(); // ผลลัพธ์: Name: Apple. Color: Red.

// 3. สามารถสร้าง Object ชิ้นใหม่และส่งค่าต่างกันได้ทันที
$banana = new Fruit('Banana', 'Yellow');
$banana->get_details(); // ผลลัพธ์: Name: Banana. Color: Yellow.
?>

🔑 สรุปให้จำง่ายที่สุด

คิดว่า __construct() คือ "ปุ่มเปิดสวิตช์ตั้งค่าเริ่มต้น" ทันทีที่คุณกดปั๊มโมเดลออบเจกต์ออกมา ตัวแปรทุกอย่างจะถูกประกอบร่างและใส่ข้อมูลให้เสร็จสรรพพร้อมใช้งานในบรรทัดเดียว
