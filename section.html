What are Classes and Objects?

Class (คลาส): คือ "แบบแปลน" หรือ "แม่พิมพ์" ที่ยังไม่มีตัวตนอยู่จริง เป็นแค่การระบุว่าสิ่งนี้จะมีคุณลักษณะ (Properties) 
อะไรบ้าง และทำอะไรได้ (Methods) บ้าง/Object (ออบเจกต์): คือ "ชิ้นงานจริง" ที่ถูกปั๊มออกมาจากแม่พิมพ์นั้นๆ 
มีตัวตนอยู่จริงในหน่วยความจำ และสามารถมีมูลค่าของข้อมูลที่แตกต่างกันได้

Classes and Objects

Class คือ "แม่พิมพ์" หรือพิมพ์เขียว (Blueprint) ที่ทำหน้าที่บอกว่าสิ่งนี้จะมีหน้าตาและทำอะไรได้บ้าง Object คือ "ชิ้นงานจริง" ที่ถูกสร้าง (ปั๊ม) ออกมาจากแม่พิมพ์นั้น เพื่อเอาไปใช้งานจริง คำสั่ง new คือ ตัวกดปั๊มชิ้นงานออกมาจากแม่พิมพ์

<?php
    class Fruit {
        // Properties
        public $name;
        public $color;

        // Method to set the properties
        function set_details($name, $color) {
        $this->name = $name;
        $this->color = $color;
        }

        // Method to display the properties
        function get_details() {
        echo "Name: " . $this->name . ". Color: " . $this->color .".
";
        }
    }
?>

Constructor Method

Constructor Method (ฟังก์ชันสร้างออบเจกต์) คือ ฟังก์ชันพิเศษในคลาสที่จะ "ทำงานโดยอัตโนมัติทันที" เมื่อเราใช้คำสั่ง new เพื่อสร้าง Object ใหม่

🛠️ Open Workshop 
        <?php
    class Fruit {
        public $name;
        public $color;

        function __construct($name, $color) {
        $this->name = $name;
        $this->color = $color;
        }

        function get_details() {
        echo "Name: " . $this->name . ". Color: " . $this->color .".
";
            }
        }

        $apple = new Fruit('Apple', 'Red');
        $apple->get_details();

        $banana = new Fruit('Banana', 'Yellow');
        $banana->get_details();
        ?>

Text Formatting

HTML provides various elements to format text...

🛠️ Open Workshop 
- <b> / <strong>: ตัวหนา / ข้อความสำคัญ
- <i> / <em>: ตัวเอียง / เน้นข้อความ
- <u> / <ins>: ขีดเส้นใต้ / ข้อความที่เพิ่มเข้ามาใหม่
- <del> / <s>: ขีดฆ่าข้อความที่ถูกลบหรือไม่ใช้แล้ว
- <small>: ตัวอักษรขนาดเล็ก
- <mark>: ไฮไลท์ข้อความ (พื้นหลังสีเหลือง)
- <sub>: ตัวห้อย (Subscript)
- <sup>: ตัวยก (Superscript)
- <blockquote>: อ้างอิงคำพูดแบบบล็อกย่อหน้า
- <code>: แสดงโค้ดสั้นๆ โปรแกรมมิ่ง

Creating Links

HTML links are defined with the a tag...

🛠️ Open Workshop 
- <a href="url" target="">Link text</a>
- Target Attributes:
    - _self: เปิดในหน้าต่างเดิม (ค่าเริ่มต้น)
    - _blank: เปิดในหน้าต่างใหม่/แท็บใหม่
- Anchor links (ลิงก์ภายในหน้า):
    - <a href="#section">Go to Section</a>
- Email links:
    - <a href="mailto:support@example.com">Email Us</a>
- Download links:
    - <a href="file.txt" download>Download File</a>

Lists (Ordered and Unordered)

HTML lists are defined with the ul, ol, and li tags...

🛠️ Open Workshop 
- <ul>: Unordered list (รายการแบบไม่มีลำดับตัวเลข - ใช้จุดวงกลม/เหลี่ยม)
- <ol>: Ordered list (รายการแบบเรียงลำดับ ตัวเลข/ตัวอักษร)
- <li>: List item (สมาชิกในรายการ)

List Style Examples:
- <ul style="list-style-type: square;">
- <ol type="A" start="3"> (เริ่มที่ตัว C)
- <ol style="list-style-type: lower-roman;"> (เลขโรมันพิมพ์เล็ก)

HTML Forms

HTML forms are used to collect user input...

🛠️ Open Workshop 
หัวข้อเกี่ยวกับฟอร์ม:
1. โครงสร้าง: <form action="server.php" method="POST">
2. ชนิดอินพุต: text, password, email, radio, checkbox, date, file
3. กล่องข้อความใหญ่: <textarea>
4. ตัวเลือกดรอปดาวน์: <select> และ <option>
5. ป้ายกำกับอินพุต: <label for="input_id"> ช่วยเรื่องการกดและ Accessibility
6. ตัวช่วย HTML5: placeholder (คำใบ้ข้อความ), required (บังคับกรอก)

- <footer>: ส่วนท้ายของหน้าเว็บ
